# مقدمة

**الشبكة المفتوحة (TON)** هي منصة لامركزية مصممة لتشغيل إنترنت مملوك للمستخدم.
تجمع بين تقنيات رئيسية — _TON Blockchain وTON DNS وTON Storage وTON Sites_ وTON Proxy — في نظام بيئي متماسك واحد.

**TON Blockchain** هو جوهر TON، وقد تم بناؤه كحاسوب فائق موزع يشغّل الخدمات والتطبيقات لإنترنت لامركزي. يهدف إلى دعم ملايين المستخدمين والتطبيقات حول العالم.

ابدأ استكشاف TON من خلال نقاط الدخول الرئيسية.
افهم البلوكتشين، اكتشف التطبيقات الأساسية، قارن مع Ethereum، أو تعمق في موارد التعلم.
