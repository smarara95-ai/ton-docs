# المقدمة

مرحبًا بك في الوثائق الرسمية للمطورين الخاصة بـ **TON Blockchain**.

صُمم هذا القسم _للمطورين الذين يبنون تطبيقات متقدمة وعقودًا ذكية على TON_. وهو يقدّم شروحات متعمقة وأمثلة تنفيذية وأفضل الممارسات.
