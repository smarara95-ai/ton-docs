# نظرة عامة

يحتوي هذا القسم على الوثائق الأصلية التي كتبها _Dr. Nikolai Durov_، وتقدم نظرة شاملة إلى جميع جوانب TON.

## الوثائق الأصلية

:::info
قد تشير الشيفرة والتعليقات والوثائق إلى "gram" و"nanogram". وهذه بقايا من كود TON الأصلي الذي طورته Telegram. لم تُصدر عملة Gram المشفرة مطلقًا؛ والعملة الرسمية لـ TON هي Toncoin، بينما تستخدم شبكة الاختبار لـ TON عملة Test Toncoin. 
:::

- [ورقة TON البيضاء](https://docs.ton.org/ton.pdf): نظرة عامة على TON ‏(The Open Network) Blockchain.

- [TON Virtual Machine](https://docs.ton.org/tvm.pdf): قد تحتوي الورقة البيضاء الخاصة بـ TON Virtual Machine على معلومات قديمة عن opcode؛ وتتوفر القائمة الحالية في قسم [تعليمات TVM](/v3/documentation/tvm/instructions).

- [TON Blockchain](https://docs.ton.org/tblkch.pdf): وصف قد يحتوي على معلومات قديمة.

- [بروتوكول إجماع Catchain](https://docs.ton.org/catchain.pdf): شرح لبروتوكول الإجماع المتحمّل للأخطاء البيزنطية (BFT) الذي يستخدمه TON Blockchain لإنشاء الكتل.

- [وثائق Fift](https://docs.ton.org/fiftbase.pdf): دليل إلى لغة البرمجة Fift وتطبيقاتها داخل TON.
