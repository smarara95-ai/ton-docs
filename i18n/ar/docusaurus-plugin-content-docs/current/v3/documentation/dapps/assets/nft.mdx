# NFT

## نظرة عامة

الرموز غير القابلة للاستبدال (NFTs) هي أصول رقمية تمثل رموزًا غير قابلة للاستبدال ضمن منظومة TON، كما هو معرف في معايير NFT التالية:

- [معيار NFT](https://github.com/ton-blockchain/TEPs/blob/master/text/0062-nft-standard.md)
- [معيار SBT](https://github.com/ton-blockchain/TEPs/blob/master/text/0085-sbt-standard.md)
- [معيار عوائد NFT](https://github.com/ton-blockchain/TEPs/blob/master/text/0066-nft-royalty-standard.md)
- [معيار NFT 2.0](/v3/documentation/dapps/assets/nft-2.0)

NFTs لامركزية وتتجنب نقاط الفشل الأحادية والاختناقات.
كل NFT في مجموعة معينة هو عقد ذكي منفصل.

يمكنك أدناه العثور على الوثائق والأدوات وأفضل الممارسات لدمج NFTs في تطبيقك اللامركزي، بما في ذلك كيفية السك والنقل والاستعلام عن مجموعات NFT وعناصرها.
