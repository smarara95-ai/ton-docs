# جتون

الجتونات هي أصول رقمية تمثل رموزًا قابلة للاستبدال ضمن منظومة TON، كما هو محدد في [معيار Jettons](https://github.com/ton-blockchain/TEPs/blob/master/text/0074-jettons-standard.md).

الجتونات هي رموز لامركزية تعمل على TON، وتتجنب نقاط الفشل والاختناقات الواحدة. يتم تخزين رصيد جتون كل مستخدم في عقد محفظة جتون منفصل.
تتفاعل العقود الذكية مباشرة مع بعضها البعض، مما يوزع الحمل عبر الشبكة بأكملها.
مع زيادة عدد المستخدمين والمعاملات، تحافظ الشبكة على توزيع متساوٍ للحمل، مما يسمح بقابلية التوسع بسهولة.

فيما يلي، يمكنك العثور على التوثيقات والأدوات وأفضل الممارسات لدمج جتونات في تطبيقك اللامركزي.

## أدوات نشر الجتون

الجتونات هي رموز مخصصة قابلة للاستبدال على بلوكشين TON. يمكنك إنشاء الرمز الخاص بك على البلوكشين باستخدام مثال Jetton Deployer أدناه:

- [TON Minter](https://minter.ton.org/) — تطبيق مفتوح المصدر لنشر الجتونات
- [عقود Jetton Deployer](https://github.com/ton-defi-org/jetton-deployer-contracts) (FunC, TL-B)
- [الواجهة الإلكترونية لـ Jetton Deployer](https://github.com/ton-defi-org/jetton-deployer-webclient) (React, TypeScript)
