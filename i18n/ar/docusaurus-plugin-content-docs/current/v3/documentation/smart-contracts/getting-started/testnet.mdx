# Testnet

Testnet هي شبكة بلوكتشين مستقلة تحاكي وظائف Mainnet باستخدام رموز عديمة القيمة.

استخدم Testnet لتطوير وتصحيح الأخطاء بأمان قبل النشر على Mainnet.

:::info
عملة Toncoin وغيرها من الأصول على Testnet ليس لها أي قيمة، ويمكن إعادة تعيين الشبكة في أي وقت.
:::

## الخدمات الأساسية

تعكس Testnet بنية Mainnet التحتية، بما في ذلك المحافظ وواجهات برمجة التطبيقات (APIs) والجسور وغيرها:


| الخدمة               | الرابط |
|-----------------------|------|
| المستكشف            | [testnet.tonscan.org](https://testnet.tonscan.org) |
| محفظة الويب          | [wallet.ton.org](https://wallet.ton.org/?testnet=true) |
| إضافة المتصفح   | [تثبيت](https://chrome.google.com/webstore/detail/ton-wallet/nphplpgoakhhjchkkhmiggakijnkhfnd) و[التبديل إلى Testnet](https://github.com/toncenter/ton-wallet/blob/master/readme.md#switch-between-mainnet-and-testnet) |
| TON Center API      | [testnet.toncenter.com](https://testnet.toncenter.com) |
| TON HTTP API        | [testnet.tonapi.io](https://testnet.tonapi.io/) |
| الجسر (Bridge)              | [bridge.ton.org](https://bridge.ton.org/?testnet=true) |
