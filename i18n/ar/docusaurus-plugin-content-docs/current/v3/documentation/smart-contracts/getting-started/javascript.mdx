# Blueprint

![Blueprint logo](/img/blueprint/logo.svg)

Blueprint هي بيئة تطوير متكاملة (all-in-one) مصممة لتحسين عملية إنشاء واختبار ونشر العقود الذكية على TON Blockchain.

## الاستخدام

قم بتشغيل الأمر التالي في الطرفية لإنشاء مشروع جديد، ثم اتبع التعليمات الظاهرة على الشاشة:

```bash
npm create ton@latest
```

### الميزات الأساسية

- سير عمل مبسّط لبناء واختبار ونشر العقود الذكية
- نشر بسيط للغاية على mainnet/testnet باستخدام محفظتك المفضلة (مثل Tonkeeper)
- اختبار فائق السرعة لعدة عقود ذكية في بلوكتشين معزول يعمل داخل العملية نفسها (in-process)

### المتطلبات

- [Node.js](https://nodejs.org/) بإصدار حديث مثل v18، تحقق من الإصدار باستخدام `node -v`
- بيئة تطوير مزودة بـ [إضافات TON](/v3/documentation/smart-contracts/getting-started/ide-plugins)
