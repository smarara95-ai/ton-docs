# مقدمة

يعتمد إنشاء العقود الذكية وتطويرها ونشرها على TON Blockchain على [TON Virtual Machine (TVM)](/v3/documentation/smart-contracts/overview#ton-virtual-machine-tvm) وعلى إحدى لغات البرمجة التالية:

- [Tolk](/v3/documentation/smart-contracts/tolk/overview) – لغة الجيل التالي لتطوير العقود الذكية على TON، بصياغة حديثة، وأنواع قوية، وتسلسل مضمّن.
- [FunC](/v3/documentation/smart-contracts/func/overview) – لغة بسيطة ذات أسلوب وظيفي، صُممت لكتابة عقود TON الذكية منخفضة المستوى والمرتبطة بإحكام بنموذج TVM.
- [Fift](/v3/documentation/smart-contracts/fift/overview) – لغة مبنية على المكدس لـ TON، وتُستخدم للنشر والاختبار والتفاعل المباشر مع TVM.

## البدء السريع

إذا أردت البدء مباشرة، فاتبع [دليل البدء السريع](/v3/guidelines/quick-start/developing-smart-contracts/setup-environment/) الخاص بنا.

## بيئة التطوير

لبناء العقود الذكية على TON واختبارها، من الأفضل إعداد بيئة تطوير محلية. والمكوّنات الأساسية هي:

- [Blueprint](/v3/documentation/smart-contracts/getting-started/javascript) – سلسلة أدوات متكاملة لإنشاء العقود الذكية واختبارها ونشرها.

- [IDE plugins](/v3/documentation/smart-contracts/getting-started/ide-plugins) – تتوفر إضافات TON الرسمية في المحررات الشائعة مثل JetBrains IDEs وVisual Studio Code وغيرها.

- [Testnet](/v3/documentation/smart-contracts/getting-started/testnet) – شبكة اختبار لأغراض التطوير. تتيح لك هذه الشبكة التطوير بأمان وكفاءة قبل الانتقال إلى Mainnet.
