# المعلمات والحدود

تحتوي هذه الوثيقة على الحدود والمعلمات الحالية المستخدمة في TON blockchain.

:::info
يمكنك التحقق من جميع معلمات البلوكشين مباشرةً في المستكشفات: [Tonviewer](https://tonviewer.com/config) أو [Tonscan](https://tonscan.org/config).

يمكن العثور على المعلمات المعرّفة في الشيفرة في [مستودع الشيفرة المصدرية](https://github.com/ton-blockchain/ton).
:::
