# جسر Toncoin

يتيح جسر Toncoin نقل Toncoin بين TON وEthereum Blockchain وبين TON وBSC ‏(BNB Smart Chain).

يُدار هذا الجسر بواسطة [أوراكل لامركزية](/v3/documentation/infra/bridges/toncoin-addresses).

### كيفية استخدامه

واجهة الجسر الأمامية متاحة على [ton.org/bridge](https://ton.org/bridge).

:::info
[الشيفرة المصدرية للواجهة الأمامية للجسر](https://github.com/ton-blockchain/bridge)
:::

### الشيفرة المصدرية للعقد الذكي

#### TON-ETH

- [FunC (جانب TON)](https://github.com/ton-blockchain/bridge-func)
- [Solidity (جانب Ethereum)](https://github.com/ton-blockchain/bridge-solidity/tree/eth_mainnet)

#### TON-BSC (BNB Smart Chain)

- [FunC (جانب TON)](https://github.com/ton-blockchain/bridge-func/tree/bsc)
- [Solidity (جانب BSC)](https://github.com/ton-blockchain/bridge-solidity/tree/bsc_mainnet)
